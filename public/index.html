About

Built for the student sitting at the back

Projectors are small, handwriting is hard to read from the last row, and video calls turn a classroom into a webinar. LiveClass Board keeps teaching exactly the way it already works — the teacher writes, the class watches — it just makes sure every single student, anywhere in the room or anywhere at all, sees exactly what's on the board, clearly, instantly.

⚡

Real-time, always

Every keystroke, every stroke of the whiteboard reaches students within a fraction of a second — no refresh needed.

🔍

Zoom, your way

Each student zooms their own view independently — 100% or 175%, it never changes what anyone else sees.

💻

Built for code

Syntax-highlighted editor for C, C++, Java, Python and more — made for programming classes first.

🖊

Whiteboard included

Draw diagrams, undo mistakes, and clear the board — every viewer stays pixel-identical to the teacher.

📄

Notes & PDF

One click turns the whole class into an organised, downloadable PDF — code blocks included.

📱

No installs, ever

Students just open a link or scan a QR code. Works on any phone, tablet or laptop with a browser.

How it works

Three steps, zero setup

1

Create a class

2

3

Write, draw, or code — it's on every student's screen the moment you make it.
